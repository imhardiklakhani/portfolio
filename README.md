# Hardik Lakhani | Portfolio

One-page portfolio built with plain HTML, CSS and JavaScript. No framework, no build step.

## Structure

```
index.html
style.css
script.js
assets/resume.pdf
```

## Run locally

Open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000.

## Deploy on GitHub Pages

1. Create a repository (use `yourusername.github.io` for a root URL).
2. Push all files to the `main` branch.
3. Go to Settings, then Pages, set Source to "Deploy from a branch", choose `main` and `/ (root)`, and save.
4. The site is live at `https://yourusername.github.io` within a minute or two.

## Update content

- Text: edit `index.html`.
- Colors and spacing: edit the variables at the top of `style.css`.
- Resume: replace `assets/resume.pdf` keeping the same file name.
